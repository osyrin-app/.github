# Osyrin

Osyrin is a compiler, runtime, and DSL for building agentic applications. Applications are defined in `.osy` files that compile to a runtime with security, classification, and audit handled at the platform level rather than in app code.

## Repositories

- **[design](https://github.com/osyrin-app/design)** — design archive: how the platform was thought into existence
- **[samples](https://github.com/osyrin-app/samples)** — example applications built on Osyrin
- **docs** — user documentation (coming with the platform launch)

## Status

Work in progress — the design archive shows where it's been and where it's heading.
